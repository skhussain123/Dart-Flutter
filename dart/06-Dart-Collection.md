## List
You can create a List by specifying the initial elements in a square bracket. Square bracket [] is used to represent a List.
```dart
// Integer List
List<int> ages = [10, 30, 23];

// String List
List<String> names = ["Raj", "John", "Rocky"];

// Mixed List
var mixed = [10, "John", 18.8];
```
